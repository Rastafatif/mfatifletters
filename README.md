# mfatifletters

A simple black & white blog (with a blue → green accent) on GitHub Pages, laid out after the
[Socks Studio visual atlas](https://socks-studio.com/category/visual-atlas/sounds/).

- `index.html` — **Letters**: the tile visual, then a text list of every piece of writing
- `about.html` — **About me**
- `letters/` — one page per letter (`example-project.html` is the template to copy)
- `assets/style.css` — all styling
- `assets/hero.js` — the blue → green tile visual at the top of the Letters page (wrinkles follow the cursor, ripples on click)

To add a letter: copy `letters/example-project.html`, fill it in, then add an `<li>` to the list in `index.html` linking to it.
